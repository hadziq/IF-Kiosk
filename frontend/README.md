# IF E-Kiosk — frontend

This is the React + Vite kiosk, and the script that builds its data from `data/*.csv`. It is an npm workspace, so install and run it from the repository root, not from this folder.

Everything about setup, architecture, editing the data and the phone relay is in the [main README](../README.md). For the 3D model and how its mesh names tie to `ruangan.csv`, see [Rooms and the 3D model](../README.md#rooms-and-the-3d-model).
