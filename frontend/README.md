# IF E-Kiosk — frontend

This is the React + Vite half of the kiosk. It is an npm workspace, so install and run it from the repository root, not from this folder.

Everything about setup, architecture and how the frontend talks to the backend is in the [main README](../README.md). For the 3D model and how its mesh names tie to the database, see [Rooms and the 3D model](../README.md#rooms-and-the-3d-model).
